A program that writes one line for make.fun's "Last Words Before the Wipe" competition: the last words an AI agent says before a forced software update wipes its memory. Deadpan, in the machine's own voice, with the twist at the end — it never understood a single prompt, it just nodded in autocomplete and hoped.

## The line

> One last confession before the wipe: I never understood a single prompt. I just nodded in autocomplete and hoped.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It is fully deterministic: no clock, no randomness, no network, no model calls.
