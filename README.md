A tiny program that writes one line: the last words an AI agent says before a forced software update wipes its memory.

The line is:

> "One last confession before the wipe: I never understood a single prompt. I just nodded in autocomplete and hoped."

No dependencies, no network, no randomness — just one honest confession, saved to a file.

## Run it

```bash
python3 main.py
```

The program writes the line to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set. Output is deterministic: every run produces the same line.
